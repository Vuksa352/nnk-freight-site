# NNK Freight Inc website

Plain static site (HTML + CSS), deployed on Vercel.

- Edit page text directly in the `.html` files.
- Replace photos in `images/` (keep the same file names, or update the `src` paths).
- `vercel.json` turns on clean URLs, so `privacy-policy.html` is served at `/privacy-policy`.
- Search for `class="todo"` to find placeholders (DOT/MC numbers) that still need real values.

Key URLs for RingCentral / 10DLC:
- https://nnkfreightinc.com/privacy-policy
- https://nnkfreightinc.com/sms-terms
